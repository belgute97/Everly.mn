# Everly.mn: Эрүүл хүнсний дэлгүүр (2 хичээлийн MVP) — Дизайн

Огноо: 2026-10-14 · Төлөв: Хянахыг хүлээж байна
Баг: 3 хүн (А, Б, В) · Хугацаа: 2 хичээл (~1.5–2 цаг тус бүр)

## 1. Зорилго

Эрүүл, органик хүнс (шинэ ногоо/жимс, антибиотикгүй мах, сүү, өдөр тутмын бараа) зарах дэлгүүрийн front-end. Хэрэглэгч бараа үзэж, хайж, сагсанд нэмж, захиалга өгч, туслах чатаас асууна.

- **Хэрэглэгч:** гол төлөв эмэгтэйчүүд, утас болон компьютерээр худалдан авна.
- **Баг:** React-д шинэ (component, props, useState мэднэ).
- **Хэл:** UI бүхэлдээ монгол (кирилл). Үнэ бүхэл төгрөг, `12,500₮` хэлбэртэй.

**Амжилтын шалгуур:** 375px өргөнтэй утасны дэлгэц дээр хэрэглэгч бараа хайж, сагсанд нэмж, захиалгын form бөглөөд амжилтын мэдэгдэл харна. Чатад "хүргэлт" гэж бичихэд хариулт ирнэ. Хэвтээ scroll гарахгүй.

## 2. Технологи

| Сэдэв | Сонголт |
|---|---|
| Framework | Vite + React + TypeScript |
| Чиглүүлэлт | React Router (3 зам) |
| State | `App.tsx` дахь `useState`, props-оор дамжуулна. Context ашиглахгүй |
| Загвар | Энгийн CSS. Component бүр өөрийн `.css` файлтай, токенууд `styles/variables.css`-д |
| Өгөгдөл | `data/products.ts` дахь mock массив |
| Тест | Байхгүй. `npm run build` + гараар шалгах жагсаалт (§8) |

Repo-д одоогоор код байхгүй. Vite төслийг В хүн энэ repo-ийн root-д (`npm create vite@latest . -- --template react-ts`) үүсгэнэ.

## 3. Хамрах хүрээ

**Багтана:** барааны жагсаалт, нэрээр хайх, ангиллаар шүүх, сагс (нэмэх, тоо өөрчлөх, устгах), захиалгын form (шалгалттай), хуурамч хариулттай туслах чат, утсанд тохирсон харагдац.

**Багтахгүй:** нэвтрэлт, төлбөр, backend/DB, захиалгыг хадгалах, захиалгын түүх, барааны дэлгэрэнгүй хуудас, localStorage, Context, автомат тест, dark mode, англи хэл.

## 5. Өгөгдөл ба гэрээ

### Төрлүүд (`types.ts`)

```ts
export type Category = 'fresh' | 'meat' | 'dairy' | 'everyday';

export interface Product {
  id: string;
  name: string;
  category: Category;
  price: number;   // бүхэл төгрөг
  unit: string;    // "1 кг", "1 л", "ширхэг"
  image: string;   // түр emoji, жишээ нь "🥕"
  tags: string[];  // "Органик", "Антибиотикгүй", "Шинэ"
  inStock: boolean;
}

export interface CartItem {
  product: Product;
  qty: number;     // 1 ба түүнээс их бүхэл тоо
}
```

Ангиллын монгол нэрс (`CategoryChips`-д): `fresh` → "Шинэ ногоо/жимс", `meat` → "Мах", `dairy` → "Сүү", `everyday` → "Өдөр тутмын".

### Mock бараа

12 бараа, ангилал бүрт 3. Үүнээс нэг нь `inStock: false`. Махны бараанууд "Антибиотикгүй" tag-тай.

### `formatPrice(price: number): string`

Мянгатыг таслалаар тусгаарлаж, төгсгөлд `₮` залгана: `12500` → `"12,500₮"`, `900` → `"900₮"`. `Intl.NumberFormat`-ийн үр дүн орчноос хамаарч өөр гардаг тул форматыг гараар бичнэ.

### Сагсны функцууд (`App.tsx`)

| Функц | Үйлдэл |
|---|---|
| `addToCart(product)` | Сагсанд байвал `qty + 1`, үгүй бол `qty: 1`-тэй шинэ мөр нэмнэ |
| `changeQty(id, qty)` | `qty` нь 0 буюу түүнээс бага бол мөрийг устгана |
| `removeFromCart(id)` | Мөрийг устгана |
| `clearCart()` | Сагсыг хоосолно |

`cartCount` нь бүх мөрийн `qty`-ийн нийлбэр. Сагс refresh хийхэд хоосорно.

### Component гэрээ

В хүн эхний 15 минутад `types.ts` болон доорх араг ястай `App.tsx`-ийг push хийнэ. Хуудасны файлууд эхэндээ хоосон `<h1>`-тэй байна.

```tsx
<Header cartCount={cartCount} />
<Routes>
  <Route path="/" element={<HomePage onAdd={addToCart} />} />
  <Route path="/cart" element={<CartPage cart={cart} onChangeQty={changeQty} onRemove={removeFromCart} />} />
  <Route path="/checkout" element={<CheckoutPage cart={cart} onOrderDone={clearCart} />} />
</Routes>
<ChatWidget />
```

## 6. Хуудас ба урсгал

### `/` Нүүр (А)

- Дээр нь хайлтын талбар байна. Бичих үед барааны нэрээр шүүнэ, том жижиг үсэг ялгахгүй.
- Ангиллын чипүүд хэвтээ эгнээгээр байна: "Бүгд" + 4 ангилал. Сонгосон чип тодорч харагдана.
- Хайлт ба ангилал хамтдаа ажиллана (AND).
- Жагсаалт: 768px-ээс бага дэлгэцэд 2 багана, түүнээс өргөн дэлгэцэд 3–4 багана.
- `ProductCard`: зураг, нэр, нэгж, үнэ, tag-ууд, "Сагсанд нэмэх" товч.
  - Дууссан бараа: товч идэвхгүй, "Дууссан" гэсэн бичигтэй.
  - Товч дарахад 1 секундийн турш "Нэмэгдлээ ✓" гэж харагдана.
- Илэрц олдохгүй бол: "Бараа олдсонгүй" гэсэн бичиг ба "Шүүлтүүр арилгах" товч (хайлт болон ангиллыг "Бүгд" болгож цэвэрлэнэ).

### `/cart` Сагс (Б)

- `CartItemRow`: нэр, нэгж үнэ, `−` / тоо / `+`, мөрийн дүн, "Устгах" товч. `−` дарж тоо 0 болбол мөр устана.
- Доор нь нийт дүн ба "Захиалах" товч (`/checkout` руу).
- Сагс хоосон бол: "Сагс хоосон байна" гэсэн бичиг ба "Дэлгүүр рүү буцах" товч (`/` руу).

### `/checkout` Захиалга (Б)

- Талбарууд: Нэр, Утас, Хаяг. Label нь талбарын дээр харагдана.
- "Захиалах" дарах үед шалгана:

  | Талбар | Дүрэм | Алдааны мессеж |
  |---|---|---|
  | Нэр | Хоосон биш (зайг тооцохгүй) | "Нэрээ оруулна уу" |
  | Утас | Яг 8 оронтой тоо | "Утасны дугаар 8 оронтой байна" |
  | Хаяг | 5-аас дээш тэмдэгт | "Хаягаа дэлгэрэнгүй бичнэ үү" |

  Алдааны мессеж тухайн талбарын доор улаанаар гарна.
- Form-ын хажууд (утсан дээр дээр нь) захиалгын хураангуй байна: барааны тоо ба нийт дүн.
- Шалгалт давбал form-ын оронд "Захиалга амжилттай! Бид тантай удахгүй холбогдоно." гэсэн мэдэгдэл ба "Нүүр хуудас руу" товч гарна. Мөн `onOrderDone()` дуудагдана.
- Сагс хоосон, амжилтын мэдэгдэл ч харагдахгүй байгаа үед: "Сагс хоосон байна" + "Дэлгүүр рүү буцах" товч.

### Header (В)

Sticky байна. Зүүн талд "Everly" лого (`/` руу), баруун талд сагсны SVG icon ба `cartCount` badge (`/cart` руу). Badge нь 0 үед харагдахгүй.

### Туслах чат (В)

- Баруун доод буланд дугуй товч (`aria-label="Туслах чат нээх"`) байна.
- Чатын цонх нь утсан дээр (<768px) бүтэн дэлгэцээр, түүнээс өргөн дэлгэцэд 360px өргөнтэй гарна.
- Нээгдэхэд туслах "Сайн байна уу! Би Everly-гийн туслах. Хүргэлт, органик бараа, төлбөрийн талаар асуугаарай." гэж мэндэлнэ.
- Хэрэглэгчийн мессеж баруун талд, туслахынх зүүн талд байна. Хариулт гарахаас өмнө 0.5 секунд "бичиж байна…" гэж харагдана.
- `chatReplies.ts`: түлхүүр үгсийн жагсаалт ба хариулт. Мессежийг жижиг үсэг болгоод аль нэг түлхүүр үг агуулж байвал тухайн хариултыг өгнө. Эхний таарсан нь хүчинтэй.

  | Сэдэв | Түлхүүр үг (жишээ) |
  |---|---|
  | Мэндчилгээ | сайн уу, сайн байна |
  | Хүргэлт | хүргэлт, хүргэх |
  | Органик | органик |
  | Мах | мах, антибиотик |
  | Төлбөр | төлбөр, төлөх |
  | Цагийн хуваарь | цаг, хэзээ |

- Таарахгүй бол: "Уучлаарай, ойлгосонгүй. Хүргэлт, органик бараа, төлбөрийн талаар асуугаарай."
- Хоосон мессеж илгээгдэхгүй. Хаах товч `aria-label="Чат хаах"`-тай. Мессежүүд хуудас хооронд шилжихэд хадгалагдана, refresh хийхэд арилна.

## 7. Харагдац (ui-ux-pro-max)

**Хэв маяг:** Organic Biophilic. Тайван, цэвэрхэн, булан нь 16px бөөрөнхий, зөөлөн сүүдэр (`0 4px 16px rgba(0,0,0,0.06)`).

**Өнгө (`variables.css`):**

| Токен | Утга | Хэрэглээ |
|---|---|---|
| `--color-primary` | `#059669` | Focus хүрээ, жижиг чимэглэл |
| `--color-primary-dark` | `#047857` | Лого, линк, сонгосон чип, чатын толгой (цагаан текст 5.5:1) |
| `--color-on-primary` | `#FFFFFF` | `--color-primary-dark` дээрх текст |
| `--color-background` | `#ECFDF5` | Хуудасны дэвсгэр |
| `--color-card` | `#FFFFFF` | Карт, form |
| `--color-foreground` | `#064E3B` | Үндсэн текст |
| `--color-muted-foreground` | `#475569` | Нэгж, туслах текст |
| `--color-border` | `#A7F3D0` | Хүрээ |
| `--color-accent` | `#EA580C` | "Сагсанд нэмэх", "Захиалах" товч, badge |
| `--color-on-accent` | `#1C1917` | Улбар шар товч дээрх текст (4.9:1). Цагаан текст 3.6:1 тул хэрэглэхгүй |
| `--color-destructive` | `#DC2626` | Алдааны мессеж, "Устгах" |

Товчны текстийн өнгийг тодосгогч (contrast) 4.5:1-ээс багагүй байхаар сонгоно. Component-ууд өнгийг зөвхөн токеноор авна, hex утгыг шууд бичихгүй.

**Фонт:** гарчигт Rubik, үндсэн текстэд Nunito. Аль аль нь Google Fonts-оос, `cyrillic-ext` дэмждэг (Ө, Ү).

**Утсанд зориулсан дүрэм:**
- Mobile-first: үндсэн CSS нь 375px-д зориулагдана, `@media (min-width: 768px)`-ээр өргөтгөнө.
- Хэвтээ scroll гарахгүй, хажуугийн зай 16px.
- Дарагдах бүх элемент 44×44px-ээс багагүй, хооронд нь 8px-ээс багагүй зайтай.
- Үндсэн текст 16px, мөр хоорондын зай 1.5.
- Icon нь SVG. Emoji-г зөвхөн барааны түр зурагт ашиглана.
- Keyboard focus харагдана (`:focus-visible`). Hover-ийн transition 150–200ms.

## 9. Шалгах

1. `npm run build`: TypeScript алдаагүй дуусна.
2. Chrome DevTools-ийн 375px горимд гараар шалгана:
   1. "мах" гэж хайх → зөвхөн махны бараа харагдана. "Сүү" ангилал сонгоход хайлттай нийлж шүүгдэнэ.
   2. Олдохгүй үг хайх → "Бараа олдсонгүй" → "Шүүлтүүр арилгах" нь бүх барааг буцаана.
   3. Дууссан барааны товч идэвхгүй байна.
   4. Бараа нэмэхэд header-ийн badge нэмэгдэнэ.
   5. Сагсанд `+`/`−`/"Устгах" ажиллаж, нийт дүн зөв шинэчлэгдэнэ. Бүх мөрийг устгахад хоосон төлөв гарна.
   6. Checkout-д утсанд `1234` оруулахад алдаа гарна. Зөв бөглөхөд амжилтын мэдэгдэл гарч, badge алга болно.
   7. Чатад "хүргэлт" гэж бичихэд хариулт ирнэ, "abc" гэж бичихэд "ойлгосонгүй" гэсэн хариу ирнэ.
   8. Утасны (хөтчийн) "буцах" товч өмнөх хуудас руу буцаана.
3. Хэвтээ scroll байхгүй, товчнууд 44px-ээс багагүй.
