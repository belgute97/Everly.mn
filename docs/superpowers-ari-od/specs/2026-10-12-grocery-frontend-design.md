# Everly.mn: Хүнсний онлайн дэлгүүр (Front-end) — Дизайн

## Зорилго
React сурах, portfolio бүрдүүлэх зорилгоор хүнсний онлайн дэлгүүрийн **зөвхөн front-end** хэсгийг хийнэ. Бүх өгөгдөл **mock data** байна. Backend дараа нь тусдаа хийгдэнэ. Одоохондоо зөвхөн хүнсний бараа зарна. Цаашид өөр ангилал нэмэгдэнэ.

## Техникийн шийдвэрүүд
| Сэдэв | Сонголт | Шалтгаан |
|---|---|---|
| Framework | **Vite + React Router** (SPA) | SEO шаардлагагүй, сурахад хялбар |
| Хэл | **JavaScript** | React-ийн үндсэн ойлголтуудад төвлөрөх |
| Styling | **Tailwind CSS** | Хурдан, responsive, ажлын зарад түгээмэл |
| State | **Context + useReducer** (сагс, auth) | Нэмэлт library-гүй, React-ийн үндсийг сурах |
| Тест | **Vitest + React Testing Library** | Vite-тай шууд нийцдэг |
| Өгөгдөл | **Mock data** (JSON + localStorage) | Backend-гүйгээр бүрэн ажиллана |

- UI хэл: монгол (кирилл).
- Үнэ: бүхэл төгрөг, `formatPrice` → `12,500₮`. `Intl.NumberFormat('mn-MN')`-ийн үр дүн орчноос хамаарч өөр гардаг тул форматыг гараар бичнэ.
- Барааны зураг: түр emoji. Дараа нь жинхэнэ зургаар солино.

## Mock data
- Ангилал: 6. Жимс ногоо, Мах, Сүү, Талх, Ундаа, Хуурай хүнс.
- Бараа: 18. Бараа бүр нэр, ангилал, үнэ, хэмжих нэгж, зураг, тайлбар, үлдэгдэл, онцлох эсэх гэсэн мэдээлэлтэй. 6 нь онцлох бараа, 1 нь дууссан.
- API давхарга бодит API-г дуурайж хариугаа бага зэрэг хоцроож өгнө.
- Хэрэглэгч, сесс, захиалга, сагс хөтчийн localStorage-д хадгалагдана.
- ⚠️ Mock auth нууц үгийг энгийн текстээр хадгална. Зөвхөн туршилтад зориулсан.

**Backend холбох үед:** зөвхөн API давхарга солигдоно. Хуудаснууд өөрчлөгдөхгүй.

## Хуудаснууд
| Зам | Хуудас | Агуулга |
|---|---|---|
| `/` | Нүүр | Hero, ангиллууд, онцлох бараа |
| `/products?category=&q=` | Каталог | Ангиллаар шүүх, нэрээр хайх |
| `/products/:id` | Дэлгэрэнгүй | Үнэ, тайлбар, тоо ширхэг сонгох, сагсанд нэмэх |
| `/cart` | Сагс | Тоо өөрчлөх, устгах, нийт дүн |
| `/login`, `/register` | Нэвтрэх / Бүртгүүлэх | Mock auth |
| `/checkout` 🔒 | Захиалах | Утас, дүүрэг, хаяг, хүргэлтийн цаг. Төлбөргүй |
| `/orders` 🔒 | Захиалгын түүх | Өөрийн захиалгууд, хамгийн сүүлийнх нь эхэндээ |
| `*` | 404 | |

🔒 = нэвтрэх шаардлагатай. Нэвтрээгүй хэрэглэгчийг `/login` руу шилжүүлж, нэвтэрсний дараа анхны хуудас руу нь буцаана.

**Ангилал өргөжүүлэх:** Ангиллууд өгөгдлөөр тодорхойлогддог. Шинэ төрөл нэмэхэд зөвхөн өгөгдөл нэмэхэд хангалттай, код өөрчлөх шаардлагагүй.

## Бизнесийн дүрэм
- Сагсанд нэмэх тоо ширхэг агуулахын үлдэгдлээс (`stock`) хэтрэхгүй. Дууссан барааг нэмэх боломжгүй.
- Хуудсыг refresh хийсэн ч сагс хадгалагдана.
- Checkout validation:
  - Утас 8 оронтой тоо.
  - Дүүрэг сонгосон байх. Сонголтууд нь УБ-ын 9 дүүрэг.
  - Хаяг дор хаяж 5 тэмдэгт.
  - Хүргэлтийн цаг сонгосон байх. Өнөөдөр болон маргаашийн 3 цагийн завсар.
- Бүртгэлийн нууц үг дор хаяж 6 тэмдэгт. Нэг имэйлээр давхар бүртгүүлэх боломжгүй.
- Захиалга амжилттай болбол сагс хоосорч, `/orders` хуудсанд амжилтын мэдэгдэл харагдана.

## Data flow
Хуудас өгөгдлөө API давхаргаас авна. Сагс болон хэрэглэгчийн мэдээлэл Context-оор дамжина.

## Алдаа боловсруулах
Хуудас бүр loading, error, empty гэсэн гурван төлөвтэй:
- Хоосон сагс.
- Хайлтын илэрц олдохгүй.
- Буруу `:id` → 404.

Форм талбар тус бүрийн доор алдааны мессеж харуулна.

## Тест
Vitest + React Testing Library:
- Unit тест: `formatPrice`, products/auth/orders API, cart reducer, checkout validation.
- Хуудас бүрийн тест.
- Бүтэн урсгал: бараа нэмэх → сагс → checkout → захиалгын түүх.

## Шалгах
- `npx vitest run`: бүх тест амжилттай давна.
- `npm run build`: алдаагүй build хийгдэнэ.
- `npm run dev`: хөтөч дээр дээрх бүх урсгал ажиллана. Утасны өргөнтэй (375px) дэлгэц дээр layout эвдрэхгүй.
