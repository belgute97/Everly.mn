# Everly.mn2

Органик, антибиотикгүй мах, шинэхэн хүнсний онлайн дэлгүүрийн жишиг төсөл. React + TypeScript + Vite. Бараа өгөгдөл бүгд жишээ (mock).

## Багийн гишүүд

| Гишүүн | Хэсэг |
|---|---|
| Belgute | А: бараа (каталог, хайлт, барааны хуудас) |
| Odnoo | Б: сагс, checkout, захиалга |
| Ochiroo | В: бүтэц, загвар, туслах чат, утсан дээрх харагдац |

## Шаардлага

Node.js 20 эсвэл түүнээс дээш хувилбар (nodejs.org-оос LTS). Admin эрхгүй бол nodejs.org-оос `win-x64.zip` хувилбарыг татаж, дурын хавтсанд задлаад, terminal-д `PATH`-д нэмж ашиглаж болно.

## Ажиллуулах

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build
npm run lint     # шалгалт
```

## Хавтасны бүтэц

```
src/
  data/        бараа, ангиллын mock өгөгдөл
  lib/         цэвэр туслах функцүүд (формат, хайлт, шалгалт)
  cart/        сагсны логик ба хадгалалт
  orders/      захиалгын хадгалалт
  components/  дахин ашиглах UI хэсгүүд
  pages/       хуудас бүр
  styles/      CSS
```

## Багийн дүрэм

Хүн бүр зөвхөн өөрийн хэсгийн файл дээр ажиллана. Commit хийхээс өмнө `git pull --rebase`. `.env` болон `node_modules` GitHub руу явахгүй.
